# 装填ホイールの起動時位相合わせ 設計書（gamma、2026-11-21）

装填機構を組み上げた最初の試験（2026-11-21、球なし）で、ステップ送りは 10 発/s で追従したが、ホイールの穴がストッパーの位置からずれたまま回っていた。組立のずれと、途中で電源が落ちたときのずれを、起動時に自動で合わせる。

## 実測（2026-11-21、試験ビルド st3215_test）

- ステップモード（MODE 3）では現在位置（56）はトルク ON からの相対カウントで、トルクを切ると 0、手で回しても 0 のまま。**絶対角は読めない**。
- 位置モード（MODE 0）では絶対角が読める。角度制限 0..0 のまま 4095 を超えて増えた（3951 → 4130 → 4296）が、4096 = 24 セルちょうどなので位相の計算には影響しない。
- 穴に手で合わせて読んだ 3 点: 3951、4130、4296（差 179、166。期待 170.67、手合わせの誤差 ±8 カウント = ホイール ±2°）。位相 = 位置 mod 170.67 は 25.7、34.3、29.3 → **`FEED_PHASE_OFFSET` = 30 カウント**。
- 増速 3:1 × 8 穴 = サーボ 1 回転にちょうど 24 セル。穴の位置 = 30 + k × 170.67 が常に成り立つ。

## 決めたこと

| 項目 | 決定 |
|---|---|
| いつ | `FeederTask::Connect` のたび（起動、再接続）。トルク ON の前に絶対角を読み、トルク ON の直後に一番近い穴まで動かす |
| 読み方 | MODE 0 に切り替え → 現在位置を読む → MODE 3 に戻す → トルク ON。**EEPROM 書き込みは 1 回の接続で 2 回**（MODE の往復。LOCK は RAM）。電源断で MODE 0 のまま残っても、次の接続で同じ手順を通るので問題ない |
| 計算 | rabcl `Feeder::AlignSteps(position, phase_offset)`: 位相 = (position − offset) を 1 セルで割った余り（0 以上 1 セル未満）、半セル未満なら −位相、以上なら 1 セル − 位相。round して int16。結果は ±85 以内 |
| 動かし方 | `Move(steps, FEED_SPEED, FEED_ACC)` を 1 回。`Feeder` のセル数・送信済みカウントには数えない（位相合わせは装填ではない） |
| 定数 | `robot.hpp` に `FEED_PHASE_OFFSET` 30.0f（実測値。メカを組み直したら試験ビルドの `m 0` → `r 56 2` で測り直す） |
| 失敗 | MODE の往復や位置読みに失敗したら `Connect` 失敗（1 Hz で再試行）。MODE 3 に戻せなかった場合はトルクを入れない |
| ログ | READY のログに `align=%+d (pos=%d)` を足す |

やらないこと: パッドからの微調整（必要になれば別途）、動作中の位相の監視（ステップモードでは読めない）。

## EEPROM 書き込み回数

ST3215 の EEPROM 寿命は公表されていない。1 接続 2 回、1 日 10 回起動でも年 7,300 回。一般的なマイコン内蔵 EEPROM（10 万回）なら十分だが、2026-11-16 の「ファームは EEPROM を書かない」方針の変更になる。代替は「メカで一度合わせてパッドで微調整」（EEPROM を書かない、電源断のずれは手で直す）。

## 試験（組立済み機構、球なし）

1. 通常ビルドで起動 → ログ `READY ... align=%+d` → ホイールが穴に合うか目視
2. USB-C を抜いて 24V を切り、手でホイールを半セルほど回し、24V を入れる → 起動で穴に戻るか
3. L1 短押し × 数回で穴に止まり続けるか、L1 押し続け 10 発/s のあとも穴に止まるか
