# 制御本体ファームの実機確認リスト（2026-10-25、脚 4 本、PC リンク無し）

出先で書いた制御本体（`Controller` / `CanScheduler` / `CanReceiver` / `ImuTask`、脚リンクの `BodyPosture`）を、**PC リンク（AE-FT234X）と IMU モジュールが無い状態**でどこまで確かめられるかの手順。上から順に、1 つ OK になってから次へ。README「制御の構成」の手順 1・5・7 に相当し、手順 2〜4・6 は部品が届いてから。

## 安全の前提

- 機体は台に載せ、**4 本の脚が空中で自由に動ける**状態にする（脚が床や物に当たらない）。手を脚の可動範囲に入れない。
- **緊急停止 = 24V を切る**。P4 は USB 給電で生き続ける設計なので、24V を切っても P4 のログは止まらない。24V のスイッチ（またはコネクタ）は手の届く所に。
- 書き込みは **24V を切った状態**で行う。
- 各ステップで「中止条件」に当たったら 24V を切り、ログを保存して原因を見る。次へ進まない。
- ファームの値: 脚は kp 1 Nm/rad、kd 0.1、摩擦 FF 0.25 Nm、荷重 FF 0、トルク上限 4 Nm（超えたらその脚をディセーブル、復帰は再起動）、ランプ 0.5 rad/s。途絶判定 0.5 s、フィードバック途絶 200 ms。PC からの指令が無い間は「現在位置を保持」。

## 0. 準備

- [ ] Stamp-P4 を PC の USB につなぐ（COM3）。24V は切。
- [ ] 脚 4 本の CAN2 配線、ID（0x07〜0x0A / 0x17〜0x1A）は 2026-10-23 の確認のまま。車輪モータ（DM2325）は未接続（2026-10-25 時点でつなげない）。車輪の 4 関節は `NO RESPONSE` のままで正常。
- [ ] 首のモータ（CAN1）は無し。IMU モジュールも無し（ログに INVALID が出るのが正常）。
- [ ] `components/rabcl` が 8f78a05 以降、`pio run` が SUCCESS（2026-10-25 済み）。

## 1. 書き込みと起動（24V なし）

操作: `pio run -t upload` → `pio device monitor`（115200）。

期待するログ:
- `gamma_turret_fw start (reset reason: 1)`（1 = 電源投入 / 3 = ソフトリセット。**毎回違う値で繰り返し出る = 再起動ループ**）
- `PC link on UART…`、`IMU (BNO055) on UART3: tx=G12 rx=G15`、`schedulers: CAN1 667 us x 3 joints, CAN2 500 us x 8 joints, control tick 10 ms`
- 1 秒ごとの状態ログ: `leg FR: NO RESPONSE …`（24V 無しなので全脚 NO RESPONSE）、`IMU: … INVALID samples=0 errors=N reinits=M`（モジュール無しなので errors が 10 ごとに reinits が 1 増える）、`PC: rx_frames=0 … LOST error_flags=0x…`（bit4 IMU 無効、bit5 途絶、bit6 モータ電源なし が立つ）
- CAN の統計行で `bus_off` が増えない（24V 無しでも P4 側の送信は走る。トランシーバの電源が 24V 系なら `fail` が増えるのは正常）

中止条件: 再起動ループ、`Guru Meditation` / `abort()`、ログが 1 秒ごとに出ない。

## 2. 24V 投入 → 保持

操作: 脚から手を離し、24V を入れる。

期待:
- 投入から 1 秒以内に `leg FR: enabled pos=… target=… rx=…` が 4 本とも出て、`rx` が毎秒約 250 増える（CAN2 各 250 Hz）。`err=0`。
- **脚が動かない**（`target` = `pos` のまま。ランプ目標を現在角に合わせる設計）。
- `error_flags` の bit6（モータ電源なし）が消える。bit4・bit5 は残る。
- CAN2 の統計: `sent` が毎秒約 2000（8 関節 × 250 Hz）増え、`fail=0`、`bus_error=0`、`rx_dropped=0`。

中止条件: 投入直後に脚が動く・跳ねる（→ 即 24V 断。`Reset(angle)` の経路を疑う）、`err≠0`、`bus_error` が増え続ける、どれかの脚が `NO RESPONSE`。

## 3. 保持の柔らかさ

操作: 1 本の脚を手でゆっくり 10°〜20° 動かして離す（トルク上限 4 Nm には届かない程度）。

期待:
- 押している間は弱い反力（kp 1 Nm/rad → 20° で約 0.35 Nm + 摩擦 FF 0.25 Nm）。`tor` が ±1 Nm 以内。
- 離すと元の位置へゆっくり戻る、または不感帯（0.02 rad）内で止まる。**振動しない**。
- `target` は変わらない（PC 指令が無いので目標は固定）。

中止条件: 振動・発振、離した後に行き過ぎて反対側へ振れる、`tor` が 2 Nm を超える。

## 4. トルク上限でのトリップ（今回は省略。ユーザー判断 2026-10-25。PC リンク確認のときに検討）

操作: 1 本の脚を手でしっかり押さえて動かし、`tor` を 4 Nm 以上にする（モータに無理をさせないよう短時間）。

期待:
- その脚だけ `disabled` と `tripped` 表示になり、以後その脚への指令が止まる（力が抜ける）。他の 3 本は保持を続ける。
- `error_flags` の bit0〜3 の該当ビットが立つ。LED3 の表示が変わる。
- 復帰は再起動（24V を切って P4 もリセット）。

中止条件: 他の脚まで止まる、全体が再起動する。

## 5. 24V 断 → 復電（README 手順 7）

操作: 保持状態（手順 2）で 24V を切り、3 秒待って入れる。切っている間に 1 本の脚を手で 30° くらい動かしておく。

期待:
- 切って 1 秒以内に `leg …: NO RESPONSE`、`PC:` 行に `NO-FEEDBACK` と `MOTOR-POWER-LOST`、`error_flags` の bit6 が立つ。指令は止まる（`sent` が増えない or 脚への MIT 送信が無い）。
- 入れると 1 秒以内に 4 本が `enabled` に戻り、**動かした脚は動かした位置のまま保持**（跳ねない。`reanchor` の経路）。bit6 が消える。
- これを 3 回繰り返して同じ。

中止条件: 復電で脚が跳ねる・元の位置へ勢いよく戻る、`enabled` に戻らない脚がある。

## 6. 長時間放置

操作: 保持状態で 5 分放置。

期待: `t_rotor` が上がり続けない（+10 ℃ 以内）、CAN の `fail` / `bus_error` / `rx_dropped` が 0 のまま、IMU の `reinits` が増え続けても全体の周期は乱れない（leg の `rx` が毎秒 250 のまま）。

## 7. スタック残量

README 手順 5 の esp_timer タスクのスタック残量は**ログに出していない**（最終レビューの Minor で後回し）。今回は手順 6 の間に再起動が起きないことで代用し、ログ出力は PC リンク確認のときに足す。

### 2026-10-25 の結果

- 手順 1 **OK**: 1 回起動（reset reason 11 = RTS リセット）、クラッシュなし。脚 4 本 `NO RESPONSE`、IMU は CHECK_ID で 10 エラーごとに再初期化（約 1 秒周期）、PC `LOST`、`error_flags` 0x30。CAN2 は ACK 無しで error passive（state 2、tec 128）で止まり bus off にはならない。bit6 は一度もフィードバックを受けていない間は立たない（仕様として許容、手順 5 で立つことを確認）。
- 手順 2 **OK**: 24V 投入から 1 秒以内に 4 本 `enabled`、`target` = 現在位置（FR 1.592 / FL 1.571 / BR 1.572 / BL 1.003 rad）で脚は動かず。rx 毎秒 250、CAN2 送信毎秒約 1000、tec 0、bus_error 増えず。トルク −0.007 Nm。
- 手順 3 **OK**: 右前を約 29° 動かして離す。反力は 0.51 rad ずれで 0.76 Nm（kp 1 + 摩擦 FF 0.25 の計算どおり）、目標は不変、離すと 1.594 に戻り不感帯内で静止。振動なし（手の感触）。
- 手順 5 **OK**（1 回目）: 24V 断から 1 秒以内に `disabled` + `NO-FEEDBACK` + `MOTOR-POWER-LOST`、`error_flags` 0x70。断の間に右前を 1.593 → 0.181 rad へ動かして復電 → 1 秒以内に `enabled`、`target` = 0.181（現在角に合わせ直し）、跳ねない。bit6 は消えて 0x30。
- 手順 5 **OK**（2〜4 回目）: 6 分のログの前半で 24V 断 → 復電を 3 回。いずれも断から 1 秒以内に `disabled` + bit6、復電から 1 秒以内に `enabled` + `target` = 現在角（0.206 → 0.258 → 0.574 → 1.592 rad と、断の間に動かした位置に毎回合わせ直し）、跳ねない（目視）。
- 手順 6 **OK**: 最後の約 4 分間を保持で放置。再起動なし、t_rotor 26 → 27 ℃、CAN2 tec 0 / bus_off 0 / rx_dropped 0、bus_error は 24V 断の間だけ増えて保持中は増えない、rx は毎秒 250 のまま、IMU の再初期化（約 1 秒周期）が続いても周期は乱れない。`error_flags` は 0x30（断の間 0x70）。
